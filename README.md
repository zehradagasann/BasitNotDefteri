C# Basit Not Defteri (Simple Notepad)
C# ve Windows Forms kullanılarak geliştirilmiş, kullanıcı dostu ve hafif bir metin düzenleme uygulamasıdır. Bu proje, temel dosya giriş/çıkış (I/O) işlemlerini ve Windows form kontrollerini anlamak için oluşturulmuştur.

✨ Özellikler
Dosya Oluşturma: Yeni bir temiz sayfa açarak not almaya başlayın.

Dosya Açma: Bilgisayarınızdaki mevcut .txt dosyalarını görüntüleyin.

Dosya Kaydetme: Yazdığınız metinleri istediğiniz konuma kaydedin.

Kullanıcı Dostu Arayüz: Sade ve odaklanmayı kolaylaştıran tasarım.

🛠️ Kullanılan Teknolojiler
Dil: C#

Framework: .NET Framework / .NET Core (Windows Forms)

IDE: Visual Studio 2022
